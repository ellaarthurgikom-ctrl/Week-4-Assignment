# Week-4-Assignment
BIOS 640: Assignment 4
Project Purpose
This repository contains the data analysis, R Markdown reports, and interactive dashboards for Week 4 of BIOS 640: Introduction to Health Data Science Methods. The project focuses on version control via GitHub, customizing R Markdown outputs (including HTML reports and PDF tables), and building an interactive flexdashboard to explore blood pressure trends in the NHANES dataset.

Repository Structure
data/: Contains the raw datasets used for the analysis, including cleaned_NHANES.csv and diet.csv.

code/: Contains the primary R Markdown scripts for generating the reports and dashboards.

figures/: Stores the static plots and visualizations generated during the exploratory data analysis phase.
